Drop your brand logo image in this folder (common/logo/) — EVERY new site reel picks it up automatically!

Priority order:
1. logo.png
2. logo.svg
3. logo.webp / logo.jpg
4. Any custom filename set in common/brand.json ("logo_file")
5. Built-in default placeholder: brand_logo.svg

Recommended format:
- Transparent PNG (or SVG), roughly square (e.g. 512x512 px) so it stays crisp both in the top-left HUD watermark and on the closing "Follow Our Page" CTA card.
